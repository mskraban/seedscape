How it works

Three steps. No sign-up.

Type a seed

Any word, name or date works. moonlight, 2026-10-31, your dog's name. Every seed makes a different picture, and it never changes.

Pick a style

Pixel landscapes, synthwave suns, planets, mazes, kaleidoscopes, nebulae. Mix in a palette, blur, grain and any size from a phone to 8K.

Download, animate, embed

Save a PNG, record a seamless MP4 loop, run it fullscreen as a live wallpaper, or call the API from your own site.

Why Seedscape

Made to be shared, remixed and embedded.

Truly reproducible

A seed fully determines the image, on any device, forever. Share a seed or a link and everyone sees exactly the same wallpaper. Old seeds are protected by tests, so updates never change them.

Seamless animation

Every style loops perfectly. Run it live, open the fullscreen wallpaper page, record an MP4, or fetch an animated WebP or GIF from the API.

35 styles, endless variety

Landscapes, space scenes, patterns, circuit boards and data art, with 12 palettes plus one generated from your seed. Tune pixel size, blur, grain and vignette.

A free image API

Drop a URL into an <img> tag and get a PNG, JPEG or WebP. CORS is open, results are cached forever, and the docs are one page long.

Private by design

The generator runs entirely in your browser. No accounts, no cookies, no analytics. It even works offline once you have the page.

Open source, MIT

One small drawing engine shared by the browser and the server. Adding a style is a single function. Contributions are welcome.

For developers

A wallpaper is one URL away.

No keys, no SDK. Put the parameters in the query string and use the result anywhere an image fits: a README banner, a blog header, a CSS background.

<!-- an image, anywhere -->
<img src="https://seedscape-azure.vercel.app/api/wallpaper?seed=hello&style=aurora&size=1200x400" />
# a seamless animated loop
curl -o loop.webp "https://seedscape-azure.vercel.app/api/wallpaper?seed=hello&style=planet&animate=1"
/* a CSS background */
body { background: url("https://seedscape-azure.vercel.app/api/wallpaper?seed=my-site&style=mesh&blur=6&format=webp") center / cover; }

Questions

Good to know.

What is a seed?

A seed is any text you type: a word, a name, a date. Seedscape turns it into a number and uses that number to make every random choice, so the same seed always produces exactly the same wallpaper, on any device.

Is Seedscape free, and do you collect any data?

Yes, it is free and open source under the MIT license. The generator runs entirely in your browser, needs no account, and uploads nothing. The image API is stateless and does not store or track requests.

Can I use the wallpapers commercially?

Yes. The images you generate are yours to use however you like, including commercially. The code is MIT licensed.

How do I get an animated or live wallpaper?

Tick Animate in the generator, then record a seamless loop as an MP4 or WebM video, or open the fullscreen Live page, which can also be used with live-wallpaper apps such as Lively on Windows. The API can return short animated WebP or GIF files too.

What sizes can I download?

The generator exports PNG files from tiny to 7680 pixels wide, with presets for 4K, ultrawide, MacBook, iPhone and Android screens. The image API supports up to 4096 pixels per side.

Does it work offline?

Yes. The generator is a static page with no external dependencies. Download the repository from GitHub, open app.html in a browser and everything works without internet.
