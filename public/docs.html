API reference

Wallpapers from a URL.

The Seedscape API renders a wallpaper from query parameters and returns an image. There are no keys, accounts or rate-limit tiers. The same URL always returns the same image, so it is safe to cache and to use in production pages.

Base URL: https://seedscape-azure.vercel.app · Engine version 1 · 35 styles · CORS open (*)

Quick start

<img src="https://seedscape-azure.vercel.app/api/wallpaper?seed=hello&style=aurora&palette=neon&size=1200x400" alt="Header" />

Endpoints

GET/api/wallpaperRender a wallpaper (PNG, JPEG, WebP, or animated WebP/GIF).
GET/w/:seedShort form: /w/hello?style=waves.
GET/randomA fresh random wallpaper on every request.
GET/api/randomA random seed, style and palette as JSON, with ready-to-use URLs. Add ?redirect=1 to be redirected to the image.
GET/api/stylesMachine-readable catalogue of styles, palettes, sizes, defaults and limits.

Parameters

All parameters are optional. Everything goes in the query string of /api/wallpaper.

vignette1Edge darkening, 1 or 0.
invert0Swap light and dark in the palette.

download–Add download=1 to receive a Content-Disposition: attachment filename.

Animated images

Add animate=1 to get a seamlessly looping animation. Frame i of N is drawn at loop time i ⁄ N, so the last frame flows straight back into the first. All 35 styles support it.

https://seedscape-azure.vercel.app/api/wallpaper?seed=hello&style=planet&animate=1&frames=36&fps=18&format=gif&size=640x360
ParameterDefaultDescription
animate–1 to animate.
frames24Number of frames, 4–48.
fps12Playback speed, 1–30. The loop lasts frames ÷ fps seconds.
formatwebpwebp (small, great quality) or gif (works everywhere).
size960x540Max 1 megapixel per frame, and frames × w × h ≤ 13 megapixels.
grain0Off by default: fresh grain on every frame makes files much bigger.

Responses include X-Seedscape-Frames and X-Seedscape-Fps. Each frame is a full render on a serverless function, which is why the limits are small. For longer or bigger animation use the live page or record a loop in the app; both run on your own device.

Live wallpaper page

/live is a fullscreen page that animates one wallpaper forever. Put options in the URL hash, e.g. /live#seed=hello&s=synthwave&p=Neon&d=12.

ParameterDefaultDescription
seed, s, p–Seed, style id and palette name (as in the app, e.g. Neon).
px, b4, 0Pixel size 1–16 and blur 0–30.
d12Loop length in seconds, 2–60.
c0Pick a fresh seed every c seconds.
shuffle–1 with c also picks a random style each time.
ui10 hides the on-screen hint.

Keys: R/Space new wallpaper · [ ] style · P pause · F fullscreen. It honours the system reduce motion setting. It also works as a URL in live-wallpaper tools such as Lively.

Responses & caching

  • Deterministic. The same query returns the same bytes. Responses with a seed are sent with Cache-Control: public, max-age=31536000, immutable.
  • Random images (no seed) are sent with no-store. The seed used is in the X-Seedscape-Seed header.
  • X-Seedscape-Engine is the engine version. It only changes if a change would alter what an existing seed produces.
  • HEAD and OPTIONS are supported. Errors are JSON.

Errors & limits

StatusWhen

413The encoded image would exceed the 4.5 MB response limit (rare; use format=webp).

Examples

CSS background

body { background: url("https://seedscape-azure.vercel.app/api/wallpaper?seed=my-site&style=mesh&blur=6&format=webp") center / cover fixed; }

A different wallpaper every day

const today = new Date().toISOString().slice(0, 10);  // "2026-10-31"
img.src = `https://seedscape-azure.vercel.app/api/wallpaper?seed=${today}&style=horizon`;

Python

import requests
r = requests.get("https://seedscape-azure.vercel.app/api/wallpaper",
                 params={"seed": "hello", "style": "mosaic", "palette": "game-boy", "size": "800x600"})
open("hello.png", "wb").write(r.content)
